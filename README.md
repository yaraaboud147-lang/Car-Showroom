# Car Showroom 🚗

This is a small C++ project I made while learning C++ and OOP.

The idea is a simple car showroom with different types of cars, such as cars for sale and cars for rent.

In this project, I practiced:

- Classes and objects
- Inheritance
- Polymorphism
- Virtual functions
- Function overriding
- Pointers
- Dynamic memory
- Vectors
- Constructors and destructors

The project can display cars for sale with their warranty and calculate the total cost for rented cars.

I made this project to practice OOP and understand how these concepts can be used in a simple real-life example.

I'm still learning C++, so I will probably improve this project and add more things to it later.

Thank you for checking out my project! ❤️
